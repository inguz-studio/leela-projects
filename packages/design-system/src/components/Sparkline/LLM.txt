## Import canônico
import { Sparkline, type SparklineProps } from '@leela/design-system'

## Quando usar
Mini-gráfico de linha decorativo (mockup `.sparkline`, 28px de altura) no rodapé de um KPI ou célula: tendência de uma série ≥ 2 pontos. Linha + degradê inteiros em `currentColor` — o CONSUMIDOR pinta com um token (ex.: `text-[var(--text-brand)]`).

## Quando NÃO usar
Não use como gráfico analítico (sem eixos, sem tooltip, sem interação). Não renderize com menos de 2 pontos (o componente retorna null — nunca invente série).

## Props válidas
- values: readonly number[]   (≥ 2 pontos; < 2 → null)
- 'aria-label'?: string   (com label vira role="img"; sem, é decorativa aria-hidden)
- className?: string   (é aqui que entra a COR, via classe text-[var(--…)])

## Tokens consumidos (nenhum valor cru permitido)
- --kpi-sparkline-h (altura)
- currentColor herdado do container (stroke + gradiente de fill com stop-opacity)

## Proibido (do/don't)
DON'T: stroke/fill com hex — a cor vem do container por token.
DON'T: fabricar valores para "preencher" a curva (estado honesto: sem série, sem sparkline).
DO: id de gradiente já é único por useId — pode haver várias na mesma tela.

## Exemplo mínimo (válido, copiável)
<Sparkline values={[3, 5, 4, 8, 9]} className="text-[var(--text-brand)]" />

## Exemplo completo (válido, copiável)
<Sparkline
  values={serieDeConversao}
