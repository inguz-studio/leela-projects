## Import canônico

## Quando usar
Card de evento com media 16/10, badge de modalidade sobreposto, metadados e footer. Com href vira link, com apenas onClick vira botão, sem ambos é um article estático.

## Quando NÃO usar
Não use para desafios com progresso (CardDesafio) nem como contêiner genérico de superfície (Card). É um componente de domínio de eventos.

## Props válidas
- title: string   (obrigatório)
- media: React.ReactNode   (default: undefined) — imagem/gradiente 16/10; fallback: gradiente com tokens
- modality: React.ReactNode   (default: undefined) — badge sobreposto na media (ex.: <Badge>5K</Badge>)
- meta: React.ReactNode   (default: undefined) — data, local, contadores
- footer: React.ReactNode   (default: undefined)
- href: string   (default: undefined) — renderiza <a>
- onClick: () => void   (default: undefined) — sem href, renderiza <button>
- className: string   (default: undefined)
Nenhuma outra prop existe.

## Proibido (do/don't)
DON'T: props image, imageUrl, category, date — NÃO existem; media/meta são slots ReactNode.
DON'T: aspect ratio custom na media — o 16/10 é fixo do contrato visual.
DON'T: hex, rgb, px, rem em style inline (a media do consumidor deve usar imagem ou tokens).
DO: passe modality como Badge do DS; para navegação use href (o onClick pode coexistir como tracking).
