## Import canônico
import { EventRow, type EventRowProps, type EventThumbVariant } from '@leela/design-system'

## Quando usar
Linha horizontal de evento do mockup `.event-row` (default compact): thumb 40px com gradiente por modalidade, nome + meta com dot-sep, contagem x/y à direita, badge de status e ação. Listas densas tipo "Seus eventos ativos".

## Quando NÃO usar
Não use no hub de eventos (lá o padrão é CardEvento — card vertical de mídia 16/10, anatomia disjunta; decisão de dedup registrada no T5). Não use para linhas tabulares (Table).

## Props válidas
- name: string
- thumbVariant: 'corrida' | 'ciclismo' | 'yoga' | 'virtual' | 'crossfit'
- thumbIcon?: ReactNode   (default lucide por variante: Footprints/Bike/Flower2/MonitorPlay/Dumbbell)
- metaItems?: ReactNode[]   (intercalados com dot-sep 3px)
- count?: { value: string; total?: string; label: string }
- badge?: ReactNode   (Badge de status)
- action?: ReactNode   (ex.: Button secondary sm "Gerenciar" — caminho acessível)
- onClick?: () => void   (atalho de mouse na row; a11y vive no `action`)
- className?: string

## Tokens consumidos (nenhum valor cru permitido)
- --eventrow-* (px/py/gap/thumb-size/thumb-icon-size/name-*/meta-*/dot-size/count-*)
- --thumb-corrida|ciclismo|yoga|virtual|crossfit + --thumb-icon-fg (gradientes AA provados na matriz)
- --surface-raised / --radius-lg / --radius-md / --border-default (dot-sep) / elev-1→elev-2 + motion tokens

## Proibido (do/don't)
DON'T: thumbVariant fora do enum (união fechada) ou gradiente via style inline.
DON'T: derivar a variante de dado inventado — use heurística de APRESENTAÇÃO documentada no consumidor.
DO: mantenha a ação primária no slot `action` (a row com onClick não é botão).
