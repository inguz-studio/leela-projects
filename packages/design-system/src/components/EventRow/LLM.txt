## Import canônico
import { EventRow, type EventRowProps, type EventRowMetric, type EventRowThumbImage, type EventThumbVariant } from '@leela/design-system'

## Quando usar
Linha horizontal densa de evento. Dois modos:
1. COMPACT (dashboard "Seus eventos ativos"): thumb 40px com gradiente por modalidade, nome + meta, contagem x/y única, badge, ação.
2. HÍBRIDO (hub "Meus Eventos", decisão FID-EVT-HUB): thumb com FOTO da capa (`thumbImage`) + métricas inline (`metrics`: Inscritos/Receita/Vagas) — triagem veloz do Organizador.

## Quando NÃO usar
Não use para linhas tabulares (Table). CardEvento (card vertical de mídia 16/10) continua válido para vitrines de mídia; o hub de eventos migrou para EventRow híbrido (linha densa) por decisão do produto (JOB de triagem veloz vence a vitrine).

## Responsivo (automático, sem prop)
Abaixo de `lg` (1024px) a linha reflui sozinha p/ 3 faixas à direita do thumb: nome+meta / métricas (própria linha, nunca cortam) / rodapé status+ação. Alinhamento vertical das métricas entre linhas preservado. Em lg+ o grid denso de 5 colunas é idêntico. NÃO empacote a EventRow em wrappers de scroll horizontal nem replique o refluxo no consumidor — é interno ao componente.

## Props válidas
- name: string
- thumbVariant: 'corrida' | 'ciclismo' | 'yoga' | 'virtual' | 'crossfit'  (fallback do thumb sem foto)
- thumbImage?: { src: string; alt?: string }   (FOTO da capa; substitui o gradiente. alt default "" — decorativa, o nome rotula a linha)
- thumbIcon?: ReactNode   (default lucide por variante: Footprints/Bike/Flower2/MonitorPlay/Dumbbell — ignorado quando há thumbImage)
- metaItems?: ReactNode[]   (intercalados com dot-sep 3px)
- count?: { value: string; total?: string; label: string }
- metrics?: { value: string; label: string }[]   (grupo inline `.stats-inline`; TEM PRECEDÊNCIA sobre count)
- badge?: ReactNode   (Badge de status)
- action?: ReactNode   (ex.: Button secondary sm "Gerenciar"; pode combinar menu + botão — caminho acessível)
- onClick?: () => void   (atalho de mouse na row; a11y vive no `action`)
- className?: string

## Tokens consumidos (nenhum valor cru permitido)
- --eventrow-* (px/py/gap/thumb-size/thumb-icon-size/name-*/meta-*/dot-size/count-*)
- métricas inline reusam --eventrow-count-*/-count-label-* + --spacing-5/-3 (gap/pad) + --border-subtle (divisor)
- --thumb-corrida|ciclismo|yoga|virtual|crossfit + --thumb-icon-fg (gradientes AA provados na matriz); com foto: --surface-high de base
- --surface-raised / --radius-lg / --radius-md / --border-default (dot-sep) / elev-1→elev-2 + motion tokens

## Proibido (do/don't)
DON'T: thumbVariant fora do enum (união fechada) ou gradiente via style inline.
DON'T: derivar a variante de dado inventado — use heurística de APRESENTAÇÃO documentada no consumidor.
DON'T: valores crus nas métricas — formate no consumidor (formatInt/formatBRL) e passe string pronta.
DO: mantenha a ação primária no slot `action` (a row com onClick não é botão).
DO: no hub, passe `thumbImage` do `imagemUrl` do evento e `thumbVariant` como fallback quando não houver foto.
