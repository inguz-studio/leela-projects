# Alert

O aviso em bloco: ícone com cor de severidade, fundo suave e corpo. Identidade visual por ícone + fundo — **sem borda lateral** (V2708-21 · 28/08: listra foge à identidade do produto).

O barrel tinha 78 componentes e nenhum era aviso — o checkout repetia a mesma forma quatro vezes à mão, com cinco divergências entre as cópias e nenhuma delas sendo decisão.

O canal de ARIA (`live`) é prop porque os três arquivos originais escolheram canais diferentes, cada um com a razão escrita, e estavam certos. O default é `none`: aviso que já estava na tela quando ela carregou não é live region.
