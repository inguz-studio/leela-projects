## Import canônico
import { Button, buttonVariants, type ButtonProps } from '@leela/design-system'

## Quando usar
Qualquer ação clicável do painel: submits, CTAs, ações de modal, ações de linha. Com `asChild` envolve um `<Link>` mantendo o visual de botão.

## Quando NÃO usar
Não use para navegação entre seções (use SubNav ou Sidebar) nem para filtros toggle (use Chip). Para o botão de confirmação destrutiva dentro de fluxo de confirmação, prefira ConfirmModal, que já compõe o Button correto.

## Props válidas
- variant: 'primary' | 'secondary' | 'ghost' | 'destructive'   (default: 'primary')
- size: 'sm' | 'md' | 'lg'   (default: 'md')
- asChild: boolean   (default: false) — renderiza Radix Slot, repassa props ao filho imediato
- type: 'button' | 'submit' | 'reset'   (default: 'button')
- disabled: boolean   (default: undefined) — também define aria-disabled
- ...todas as props nativas de React.ButtonHTMLAttributes<HTMLButtonElement> (onClick, className, aria-*, etc.)

- --action-destructive / --action-destructive-fg / --action-destructive-hover / --action-destructive-pressed
- --motion-duration-fast / --motion-easing-default
Aliases shadcn->brasa usados: ring-ring (= border-focus), ring-offset-background (= surface-base).

## Proibido (do/don't)
DON'T: variant="default", variant="outline", variant="link", size="icon" — nomes do shadcn stock que NÃO existem aqui; o enum é primary|secondary|ghost|destructive.
DON'T: size="xs" ou size="xl" — só existem sm|md|lg.
DON'T: hex, rgb, px, rem em style inline; nada de bg-orange-500 ou similares em className.
DO: use disabled para estado inativo (opacity e aria-disabled já são tratados); use asChild para links com visual de botão.
