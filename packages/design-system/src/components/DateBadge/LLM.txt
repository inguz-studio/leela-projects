## Import canônico
import { DateBadge, type DateBadgeProps } from '@leela/design-system'

## Quando usar
Pill de contexto temporal do mockup `.date-badge` no page-head ("Domingo, 19 de Abril · 14:32") com dot verde de "ao vivo/ok". O texto vem PRONTO do consumidor (formatador puro).

## Quando NÃO usar
Não use como badge de status (Badge) nem como data de célula de tabela (texto tertiary tabular). Não é interativo.

## Props válidas
- children: ReactNode   (o texto formatado — semântica <time> a cargo do consumidor)
- showDot?: boolean   (default true — dot verde com glow)
- className?: string

## Tokens consumidos (nenhum valor cru permitido)
- --datebadge-px / --datebadge-py / --datebadge-gap / --datebadge-font-size / --datebadge-dot-size
- --datebadge-dot-glow (box-shadow completo, literal por tema)
- --surface-overlay / --border-subtle / --text-secondary / --feedback-success (dot) / --radius-pill

## Proibido (do/don't)
DON'T: relógio "vivo" com setInterval dentro do componente — snapshot no consumidor.
DON'T: glow via box-shadow literal.
DO: envolva em <time dateTime="…"> no consumidor quando o texto for uma data real.

## Exemplo mínimo (válido, copiável)
