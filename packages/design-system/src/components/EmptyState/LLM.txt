## Import canônico
import { EmptyState, type EmptyStateProps } from '@leela/design-system'

## Quando usar
Estado vazio obrigatório em listas filtráveis: mensagem padrão, ícone opcional e slot de ação (ex.: "Limpar filtros"). A Table já o renderiza automaticamente quando data=[].

## Quando NÃO usar
Não use como placeholder de carregamento (use Skeleton) nem como mensagem de erro de operação (use Toast variant="danger").

## Props válidas
- title: string   (default: 'Nenhum item encontrado')
- description: string   (default: 'Nenhum resultado encontrado com os filtros aplicados.') — oculta quando igual ao title
- icon: React.ReactNode   (default: undefined)
- action: React.ReactNode   (default: undefined) — ex.: <Button variant="ghost">Limpar filtros</Button>
- className: string   (default: undefined)
Nenhuma outra prop existe.
