# FileInput

Seletor de arquivo do DS (upload de imagem de perfil/capa): input file real sr-only com nome acessível + gatilho Button secondary. Burro de propósito — entrega o `File` via `onFileSelected`; validação e upload vivem no api-client e nas storage.rules.

<Canvas of={Stories.Default} />

<Controls />

## Estados

- **busy** — desabilita e troca o texto do gatilho por `busyLabel` ("Enviando…").
- **erro** — `errorMessage` inline com `role=alert`, associada por `aria-describedby` (nunca só cor).
- O value é limpo a cada seleção: re-selecionar o MESMO arquivo dispara `change` de novo (re-tentativa após falha não fica muda).
