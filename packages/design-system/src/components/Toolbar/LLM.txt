## Import canônico
import { Toolbar, type ToolbarProps } from '@leela/design-system'

## Quando usar
Barra global de ferramentas no topo da área principal (mockup `.toolbar`): busca à esquerda, ações de ícone + CTA à direita, fechando em hairline. Uma por página, acima do page-head.

## Quando NÃO usar
Não use como toolbar de listagem/filtros (o padrão é `.list-toolbar` com chips locais) nem como header de página (PageHeader). Não empilhe Toolbars.

## Props válidas
- start?: ReactNode   (slot esquerdo — tipicamente SearchInput)
- end?: ReactNode     (slot direito — IconButtons + Button primário sm)
- 'aria-label'?: string   (default: 'Ferramentas globais')
- className?: string

## Tokens consumidos (nenhum valor cru permitido)
- --toolbar-gap / --toolbar-end-gap / --toolbar-mb
- --layout-toolbar-pb (fecho de 16px sobre a hairline)
- --border-subtle

## Proibido (do/don't)
DON'T: pôr navegação de abas dentro da Toolbar (use SubNav/Tabs).
DON'T: cor/espaçamento via literal.
DO: componha `end` na ordem do mockup: ajuda, notificações, CTA primário sm.

## Exemplo mínimo (válido, copiável)
<Toolbar start={<SearchInput placeholder="Buscar…" />} />

## Exemplo completo (válido, copiável)
<Toolbar
  start={<SearchInput placeholder="Buscar atleta, evento, inscrição…" />}
  end={
