## Import canônico
import { Skeleton, type SkeletonProps } from '@leela/design-system'

## Quando usar
Placeholder de carregamento: linha de texto (text), bloco retangular (rect, dimensione via className) ou círculo para avatar/ícone (circle). Shimmer respeita prefers-reduced-motion (motion-safe:animate-pulse). Decorativo: aria-hidden, sem role.

## Quando NÃO usar
Não use para estado vazio pós-carregamento (EmptyState) nem como spinner de ação em botão (use a prop disabled/loading do fluxo). Não anuncie skeletons a leitores de tela.

## Props válidas
- variant: 'text' | 'rect' | 'circle'   (default: 'rect')
- ...todas as props nativas de React.HTMLAttributes<HTMLDivElement> (className para dimensões, etc.)

## Tokens consumidos (nenhum valor cru permitido)
- --spacing-4 (altura da variante text)
- --skeleton-radius
- --radius-pill (variante circle)
Alias shadcn->brasa usado: bg-muted (= surface-overlay).

## Proibido (do/don't)
DON'T: variant="circular", variant="rectangular", variant="line" — o enum é text|rect|circle.
DON'T: props width/height numéricas — dimensione via className com tokens (ex.: w-[var(--avatar-size-md)]).
DON'T: hex, rgb, px, rem em style inline.
DO: para rect e circle defina dimensões via className usando tokens de spacing/size; espelhe o layout final para evitar salto de conteúdo.
