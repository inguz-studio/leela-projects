# CheckboxField

O par rótulo + caixinha. A procedência do controle no produto é perfeita — dezenove `Checkbox` do DS, zero checkbox nativo. O que foi escrito dezessete vezes, em três dialetos, é a montagem do rótulo.

## O rótulo com link

O `<label htmlFor>` irmão deixa um link viver dentro do rótulo sem que a tela precise tirá-lo de lá.

<Canvas of={Stories.RotuloComLink} />

## Fronteira com o `Field`

`Field` é a casca de qualquer controle com rótulo **acima**. `CheckboxField` é o par com rótulo **ao lado**. São irmãs no cânone §3 — esta peça não compõe aquela, porque montar uma coluna para depois desfazê-la em linha seria carregar a anatomia errada.
