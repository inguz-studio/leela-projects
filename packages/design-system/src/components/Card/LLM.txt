## Import canônico
import { Card, CardHeader, CardTitle, CardDescription, CardContent, CardFooter } from '@leela/design-system'

## Quando usar
Contêiner genérico de superfície (composicional, estilo shadcn): Card > CardHeader (CardTitle + CardDescription) + CardContent + CardFooter. Para blocos de conteúdo, painéis de resumo e formulários agrupados.

## Quando NÃO usar
Não use para cards de domínio: eventos usam CardEvento e desafios usam CardDesafio. Para diálogos use Modal.

Todos os subcomponentes aceitam somente props nativas HTML (nenhuma prop própria, nenhum variant):
- Card: React.HTMLAttributes<HTMLDivElement> (div)
- CardHeader: React.HTMLAttributes<HTMLDivElement> (div)
- CardTitle: React.HTMLAttributes<HTMLHeadingElement> (h3)
- CardDescription: React.HTMLAttributes<HTMLParagraphElement> (p)
- CardContent: React.HTMLAttributes<HTMLDivElement> (div)
- CardFooter: React.HTMLAttributes<HTMLDivElement> (div)
Tipos exportados no barrel (aliases das props nativas, sem prop própria): CardProps, CardHeaderProps, CardTitleProps, CardDescriptionProps, CardContentProps, CardFooterProps.

DO: siga a ordem CardHeader > CardContent > CardFooter; CardTitle já é h3 semântico.
