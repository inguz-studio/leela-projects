## Import canônico
import { Card, CardHeader, CardTitle, CardDescription, CardContent, CardFooter } from '@leela/design-system'

## Quando usar
Contêiner genérico de superfície (composicional, estilo shadcn): Card > CardHeader (CardTitle + CardDescription) + CardContent + CardFooter. Para blocos de conteúdo, painéis de resumo e formulários agrupados.

## Quando NÃO usar
Não use para cards de domínio: eventos usam CardEvento e desafios usam CardDesafio. Para diálogos use Modal.

## Props válidas
Os subcomponentes aceitam props nativas HTML. As duas únicas props próprias são de SEMÂNTICA (`as`), nunca de visual — o className é byte a byte o mesmo em qualquer tag:
- Card: React.HTMLAttributes<HTMLDivElement> + as?: 'div' | 'article' | 'section' | 'li' | 'aside' (default 'div')
- CardHeader: React.HTMLAttributes<HTMLDivElement> (div)
- CardTitle: React.HTMLAttributes<HTMLHeadingElement> + as?: 'h2' | 'h3' | 'h4' (default 'h3')
- CardDescription: React.HTMLAttributes<HTMLParagraphElement> (p)
- CardContent: React.HTMLAttributes<HTMLDivElement> (div)
- CardFooter: React.HTMLAttributes<HTMLDivElement> (div)
Tipos exportados no barrel: CardElement, CardProps, CardHeaderProps, CardTitleProps, CardDescriptionProps, CardContentProps, CardFooterProps.

## Tokens consumidos (nenhum valor cru permitido)
- --spacing-1 / --spacing-6
- --font-size-lg / --font-size-sm
- --font-weight-semibold
Aliases shadcn->brasa usados: bg-card (= surface-raised), text-card-foreground (= text-primary), text-muted-foreground (= text-tertiary), border-border (= border-default), shadow-elev-1.

## Proibido (do/don't)
DON'T: props variant, elevation, padding — NÃO existem; ajuste via className com tokens.
DON'T: CardAction ou CardMedia — não existem neste DS.
DON'T: hex, rgb, px, rem em style inline.
DON'T: usar `as` para mudar aparência. Ele muda a TAG, e só: a semântica é a razão de existir dele.
DON'T: <Card> solto dentro de <ul> — use as="li". <div> filho direto de lista quebra a semântica.
DON'T: converter <section aria-label> para <Card> sem as="section". Um <div> com aria-label e sem role não é landmark nenhum, e a conversão silenciosa apaga um marco de navegação de leitor de tela.
DO: siga a ordem CardHeader > CardContent > CardFooter; CardTitle é h3 por default e desce por `as`.
DO: cartão de ENTIDADE (clube, comunicado, campanha, parceria, afiliação) é CardDominio, que já compõe este Card com os slots certos.
