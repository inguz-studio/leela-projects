## Import canônico
import { CardDesafio, type CardDesafioProps } from '@leela/design-system'

## Quando usar
Card de desafio gameficado com barra de progresso (Vitória/feedback-success) e porcentagem; a 100% o card ganha glow de marca (elevation-brand). Progressbar acessível (role, aria-valuenow/min/max).

## Quando NÃO usar
Não use para eventos (CardEvento) nem como contêiner genérico (Card). Não é interativo: não há href/onClick — envolva em link externo se precisar navegar.

## Props válidas
- title: string   (obrigatório)
- progress: number   (obrigatório) — 0 a 100; valores fora da faixa são grampeados e arredondados
- meta: React.ReactNode   (default: undefined) — prazo, recompensa, participantes
- icon: React.ReactNode   (default: undefined) — ícone em text-brand
- className: string   (default: undefined)
Nenhuma outra prop existe.

## Proibido (do/don't)
DON'T: props onClick, href, variant, color — NÃO existem.
DON'T: progress como string ("80%") — é number 0-100.
DON'T: hex, rgb, px, rem em style inline; a cor da barra é fixa em feedback-success por contrato.
DO: passe progress cru do backend (o clamp 0-100 é interno); use meta para prazo/recompensa.
