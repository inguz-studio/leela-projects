## Import canônico
import { Tabs, type TabsProps, type TabItem } from '@leela/design-system'

## Quando usar
Troca de conteúdo IN-PAGE (Radix Tabs, tablist ARIA) com visual underline Brasa 2px na ativa e pill de contador opcional. Todos os painéis ficam no DOM (forceMount) — o inativo é apenas ocultado.

## Quando NÃO usar
Não use para navegação entre rotas — isso é SubNav (nav landmark com links). Tabs é sempre conteúdo na mesma página.

## Props válidas
- tabs: TabItem[]   (obrigatório) — TabItem = { id: string; label: string; count?: number; content: React.ReactNode }
- defaultTab: string   (default: primeira tab) — modo não controlado
- value: string   (default: undefined) — modo controlado
- onValueChange: (id: string) => void   (default: undefined)
- 'aria-label': string   (default: 'Abas')
- className: string   (default: undefined)
Nenhuma outra prop existe.

Aliases shadcn->brasa usados: ring-ring (= border-focus), bg-background (= surface-base) no pill de contador.

## Proibido (do/don't)
DON'T: subcomponentes TabsList/TabsTrigger/TabsContent do shadcn stock — NÃO são exportados; a API é declarativa via tabs.
DON'T: visual pill do stock (bg-muted na lista) — o visual é underline por contrato §2.14.
DON'T: remover painéis inativos do DOM — o forceMount é intencional (busca em página).
DON'T: hex, rgb, px, rem em style inline.
DO: prefira modo não controlado (defaultTab); use value + onValueChange só quando outra parte da tela precisa reagir à aba ativa.
