## Import canônico
import { Pagination, type PaginationProps } from '@leela/design-system'

## Quando usar
Controle de paginação para listas densas (DoD Tela: listas com 50+ itens). Mostra "Mostrando X–Y de Z", página atual e botões anterior/próximo.

## Quando NÃO usar
Não use para carrosséis nem para o Stepper de fluxo (etapas de checkout usam Stepper). Sem itens suficientes para paginar, omita o componente.

## Props válidas
- total: number   (obrigatório) — total de itens
- page: number   (obrigatório) — página atual, 1-based
- pageSize: number   (obrigatório)
- onPageChange: (page: number) => void   (obrigatório)
- className: string   (default: undefined)
Nenhuma outra prop existe.

## Proibido (do/don't)
DON'T: props totalPages, currentPage, siblingCount, showFirstLast — NÃO existem; o cálculo de páginas é interno a partir de total/pageSize.
DON'T: page 0-based — a primeira página é 1.
DON'T: hex, rgb, px, rem em style inline.
DO: guarde page no estado do consumidor e atualize em onPageChange; os botões já desabilitam nas bordas.
