# Thumb

Miniatura de mídia de entidade para reconhecer o item de vista antes de clicar: imagem de kit, logo de marca, capa do evento. A largura vem do token do tamanho e a altura sai da razão contratada pelo dado (1:1 para logo e kit, 1.9:1 para capa). Sem imagem — ou com a URL quebrada — cai sozinho num fallback digno.

<Controls />

## Sem imagem

O fallback recebe uma sigla curta ou um ícone. É ele que separa "esta entidade não tem imagem" de "a imagem quebrou": nos dois casos a tela mostra a mesma caixa íntegra, nunca o quadrado partido do navegador.
