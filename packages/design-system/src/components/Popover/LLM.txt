## Import canônico
import { Popover, type PopoverProps, type PopoverAction } from '@leela/design-system'

## Quando usar
Apenas em código legado que já importa Popover: é um re-export 1:1 do DropdownMenu (Popover = DropdownMenu, PopoverProps = DropdownMenuProps, PopoverAction = DropdownMenuAction). Não há implementação própria neste diretório.

## Quando NÃO usar
Em código NOVO: use DropdownMenu — Popover é @deprecated e existe só para estabilidade da API das telas do painel. Não use para conteúdo flutuante arbitrário; a API é um menu de ações.

## Props válidas
Idênticas a DropdownMenuProps (ver src/components/DropdownMenu/LLM.txt):
- actions: PopoverAction[]   (obrigatório) — PopoverAction = { id: string; label: string; onClick: () => void; destructive?: boolean; disabled?: boolean }
- open: boolean   (obrigatório)
- onOpenChange: (open: boolean) => void   (obrigatório)
- trigger: React.ReactElement   (obrigatório)
- align: 'left' | 'right'   (default: 'right')
- className: string   (default: undefined)

## Proibido (do/don't)
DON'T: PopoverTrigger/PopoverContent/PopoverAnchor do Radix ou shadcn stock — NÃO existem neste DS.
DON'T: usar Popover em código novo — prefira DropdownMenu.
DON'T: hex, rgb, px, rem em style inline.
DO: migre imports de Popover para DropdownMenu quando tocar no arquivo.
