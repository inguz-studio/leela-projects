## Import canônico
import { Popover, PopoverTrigger, PopoverContent, PopoverAnchor, PopoverClose } from '@leela/design-system'

## Quando usar
Painel flutuante ancorado a um trigger (conteúdo arbitrário do DS): base do Combobox, do Calendar/DateRangePicker e de qualquer overlay posicionado. O painel que abre é DO DS (bg-popover, borda, shadow), nunca a caixa do sistema operacional. Wrapper fino sobre @radix-ui/react-popover — a11y (foco, Esc, click-fora, colisão/flip) vem da lib.

## Quando NÃO usar
Menu de AÇÕES (ver/editar/excluir) — use DropdownMenu (o antigo Popover de menu do E01). Seleção rica filtrável — use Combobox. Tooltip — use Tooltip.

## Composição (compound)
- Popover (Root): open?/onOpenChange? (controlado) ou não-controlado.
- PopoverTrigger: o gatilho. Use asChild para passar um <Button/> próprio.
- PopoverContent: o painel. align (default 'start'), sideOffset (default 4), className.
- PopoverAnchor / PopoverClose: âncora alternativa e botão de fechar.

## Tokens consumidos (nenhum valor cru permitido)
- --popover-min-width
- --spacing-1 / --spacing-4
- bg-popover / text-popover-foreground / border-border (aliases shadcn→brasa)
- shadow-elev-2, rounded-md

## Proibido (do/don't)
DON'T: hex, rgb, px, rem em style inline.
DO: use asChild no PopoverTrigger para reusar Button do DS.

## Exemplo mínimo (válido, copiável)
<Popover>
  <PopoverTrigger asChild><Button variant="secondary">Abrir</Button></PopoverTrigger>
  <PopoverContent>Conteúdo do DS</PopoverContent>
</Popover>

## Instrução para o modelo (colar no system prompt)
Use Popover apenas com a composição acima. Menu de ações = DropdownMenu; seleção filtrável = Combobox. Nunca aplique cor ou espaço via literal; use somente tokens do design system.
