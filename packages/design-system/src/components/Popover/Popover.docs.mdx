# Popover

Primitivo de ÂNCORA shadcn/Radix (S-R9-05 · governança §8): posiciona um painel do DS junto a um trigger, em portal, com colisão/flip e dismiss a11y (Esc, click-fora). É a base do `Combobox` e do `Calendar`/`DateRangePicker` — o painel que abre é DO DS, nunca a caixa do sistema operacional. O antigo Popover de menu do E01 virou `DropdownMenu`.
