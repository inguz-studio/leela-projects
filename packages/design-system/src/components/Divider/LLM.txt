## Import canônico
import { Divider, type DividerProps } from '@leela/design-system'

## Quando usar
Separador visual entre blocos de conteúdo, horizontal ou vertical, com três pesos (subtle, default, strong). Baseado em Radix Separator com role="separator" e aria-orientation.

## Quando NÃO usar
Não use dentro de Table (as linhas já têm border-b própria) nem como underline de aba (SubNav/Tabs têm indicador próprio).

## Props válidas
- variant: 'subtle' | 'default' | 'strong'   (default: 'default')
- orientation: 'horizontal' | 'vertical'   (default: 'horizontal')
- ...todas as props de React.ComponentPropsWithoutRef<SeparatorPrimitive.Root> exceto orientation (decorative, className, etc.)

## Tokens consumidos (nenhum valor cru permitido)
- --border-subtle
- --border-strong
- --divider-thickness
- --spacing-2
Alias shadcn->brasa usado: bg-border (= border-default) na variante default.

## Proibido (do/don't)
DON'T: variant="light", variant="heavy", variant="dashed" — o enum é subtle|default|strong.
DON'T: orientation="x" / "y" — os valores são horizontal|vertical.
DON'T: hex, rgb, px, rem em style inline; não redefina espessura via className.
DO: em layout vertical o contêiner precisa de altura definida (h-full vem do componente).

## Exemplo completo (válido, copiável)
<Divider variant="strong" orientation="vertical" />
