## Import canônico
import { Stepper, type StepperProps, type StepperStep } from '@leela/design-system'

## Quando usar
Indicador de etapas de fluxo linear (checkout usa 5 etapas): concluída (Brasa + check), atual (ring brand + aria-current="step"), futura (surface-overlay). Conector entre etapas acompanha o estado.

## Quando NÃO usar
Não use para navegação livre entre seções (SubNav/Tabs) nem para progresso percentual contínuo (CardDesafio tem progressbar). O Stepper é indicador, não recebe onClick por etapa.

## Props válidas
- steps: StepperStep[]   (obrigatório) — StepperStep = { id: string; label: string }
- current: number   (obrigatório) — índice 0-based da etapa atual
- 'aria-label': string   (default: 'Progresso das etapas')
- className: string   (default: undefined)
Nenhuma outra prop existe.

## Proibido (do/don't)
DON'T: current 1-based — a primeira etapa é current={0}.
DON'T: props onStepClick, completed[], orientation — NÃO existem; o estado deriva todo de current.
DON'T: hex, rgb, px, rem em style inline.
DO: avance current no estado do consumidor conforme o fluxo progride; etapas antes de current são marcadas concluídas automaticamente (com sr-only "(concluída)").
