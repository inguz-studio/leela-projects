## Import canônico
import { Breadcrumb, type BreadcrumbProps, type BreadcrumbItem } from '@leela/design-system'

## Quando usar
Trilha de navegação hierárquica no topo de páginas de detalhe. O último item recebe aria-current="page" automaticamente e não é clicável.

## Quando NÃO usar
Não use para navegação entre seções irmãs (use SubNav) nem para troca de conteúdo in-page (use Tabs).

## Props válidas
- items: BreadcrumbItem[]   (obrigatório) — BreadcrumbItem = { label: string; href?: string }
- className: string   (default: undefined)
Nenhuma outra prop existe; o componente não repassa atributos HTML arbitrários.

## Tokens consumidos (nenhum valor cru permitido)
- --spacing-2
- --font-size-sm
- --font-weight-semibold
- --text-secondary
- --radius-sm
- --motion-duration-fast
Aliases shadcn->brasa usados: text-foreground (= text-primary), text-muted-foreground (= text-tertiary) no separador, ring-ring (= border-focus).

## Proibido (do/don't)
DON'T: subcomponentes BreadcrumbList/BreadcrumbItem/BreadcrumbLink/BreadcrumbSeparator do shadcn stock — NÃO são exportados; a API é a prop items.
DON'T: prop separator — o separador é sempre "/" (aria-hidden), não configurável.
DON'T: hex, rgb, px, rem em style inline.
DO: omita href no item final (ele vira o item atual) e em itens não navegáveis.

## Exemplo mínimo (válido, copiável)
<Breadcrumb items={[{ label: 'Eventos', href: '/eventos' }, { label: 'Corrida da Serra' }]} />

## Exemplo completo (válido, copiável)
<Breadcrumb
  items={[
    { label: 'Painel', href: '/' },
    { label: 'Eventos', href: '/eventos' },
    { label: 'Corrida da Serra' },
  ]}
  className="mb-[var(--spacing-4)]"
/>
