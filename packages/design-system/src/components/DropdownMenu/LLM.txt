## Import canônico
import { DropdownMenu, type DropdownMenuProps, type DropdownMenuAction } from '@leela/design-system'

## Quando usar
Menu de ações flutuante ancorado a um trigger (padrão: ações por linha de Table via renderActions). Controlado (open/onOpenChange), renderiza em portal, teclado WAI-APG completo (setas, Home/End, Esc, Tab fecha).

## Quando NÃO usar
Não use para dicas de texto (Tooltip) nem para formulários flutuantes (Modal). Popover é apenas um alias @deprecated deste componente — em código novo use sempre DropdownMenu.

## Props válidas
- actions: DropdownMenuAction[]   (obrigatório) — DropdownMenuAction = { id: string; label: string; onClick: () => void; destructive?: boolean; disabled?: boolean; checked?: boolean; count?: number; icon?: React.ReactNode }
- open: boolean   (obrigatório) — controlado pelo consumidor
- onOpenChange: (open: boolean) => void   (obrigatório)
- trigger: React.ReactElement   (obrigatório) — elemento único (ex.: <Button/>); recebe onClick/aria-haspopup/aria-expanded/aria-controls via Radix Slot
- align: 'left' | 'right'   (default: 'right')
- side: 'bottom' | 'top'   (default: 'bottom') — borda vertical de ancoragem; 'top' abre ACIMA do trigger (caso: trigger colado na borda inferior do viewport, ex.: rodapé de perfil do SidebarRail)
- menuLabel: string   (default: 'Ações') — nome acessível do menu (role="menu")
- className: string   (default: undefined) — aplicada no PAINEL do menu (o popover em portal), NÃO no trigger
- containerClassName: string   (default: undefined) — aplicada no wrapper de ancoragem do trigger (inline-flex); use p/ o trigger ocupar a largura do pai (ex.: w-full)

## Tokens consumidos (nenhum valor cru permitido)
- --spacing-1 / --spacing-3
- --popover-min-width / --popover-icon-size (ícone do item)
- --icon-stroke (traço do ícone do item)
- --btn-height-sm
- --font-size-base
- --text-primary / --text-danger
- --feedback-danger-surface
- --motion-duration-fast
Aliases shadcn->brasa usados: bg-popover (= surface-overlay), text-popover-foreground (= text-primary), border-border (= border-default), shadow-elev-2, bg-accent/text-accent-foreground (= action-ghost-hover/-fg), ring-ring (= border-focus).

## Proibido (do/don't)
DON'T: subcomponentes DropdownMenuTrigger/DropdownMenuContent/DropdownMenuItem do shadcn stock — NÃO existem; a API é declarativa via actions.
DON'T: uso não controlado (sem open/onOpenChange) — não há defaultOpen.
DON'T: align="center" — align só aceita left|right. Eixo vertical é side (bottom default; top só quando abrir para baixo sairia da tela).
DON'T: hex, rgb, px, rem em style inline.
DON'T: className de tamanho no elemento passado em `icon` — o wrapper do DS já aplica --popover-icon-size e --icon-stroke no SVG filho; classe do consumidor aqui é como o rail acabou com três tamanhos de ícone.
DON'T: `icon` como nome em string — o campo recebe o ELEMENTO pronto (icon={<Settings />}); o DS tem lucide-react como peer e não mantém tabela de nomes.
DO: use `icon` quando o item é ação nomeada e reconhecível (Configurações, Sair); ícone decorativo — o rótulo continua sendo o nome acessível.
DO: para "só um menu aberto por vez" em Table, guarde no pai um único id aberto; marque ações destrutivas com destructive: true.

## Exemplo mínimo (válido, copiável)
<DropdownMenu
  actions={[{ id: 'editar', label: 'Editar', onClick: editar }]}
  open={aberto}
  onOpenChange={setAberto}
  trigger={<Button variant="ghost" size="sm">Ações</Button>}
/>

## Exemplo completo (válido, copiável)
<DropdownMenu
  align="right"
  actions={[
    { id: 'editar', label: 'Editar', onClick: editar },
    { id: 'duplicar', label: 'Duplicar', onClick: duplicar, disabled: !podeDuplicar },
    { id: 'excluir', label: 'Excluir', onClick: confirmarExclusao, destructive: true },
  ]}
  open={abertoId === evento.id}
  onOpenChange={(o) => setAbertoId(o ? evento.id : null)}
  trigger={<Button variant="ghost" size="sm" aria-label="Ações do evento">...</Button>}
/>
