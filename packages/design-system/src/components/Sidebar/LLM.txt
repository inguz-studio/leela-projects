## Import canônico
import { Sidebar, SidebarFooter, DEFAULT_SIDEBAR_SECTIONS, sidebarNavIcon, type SidebarProps, type SidebarSection, type SidebarItem, type SidebarFooterProps } from '@leela/design-system'

## Quando usar
Navegação lateral do shell, FIXA em 240px (--sidebar-width) — sem modo colapsado. Use DEFAULT_SIDEBAR_SECTIONS para as seções padrão do painel Be Hero e sidebarNavIcon(IconeLucide) para ícones nos tokens do DS.

## Quando NÃO usar
Não use para menus contextuais (use DropdownMenu) nem para sub-navegação de página (use SubNav). Não implemente toggle de colapso: a variante fixa substitui o modo colapsável por decisão vinculante.

## Props válidas
Sidebar:
- sections: SidebarSection[]   (obrigatório) — SidebarSection = { label: string; items: SidebarItem[] }; SidebarItem = { id: string; label: string; icon: React.ReactNode; href?: string; badge?: string | number; active?: boolean; onClick?: () => void }
- footer: React.ReactNode   (default: undefined) — ex.: <SidebarFooter ... />
- className: string   (default: undefined)
SidebarFooter:
- name: string   (obrigatório)
- avatar: React.ReactNode   (default: undefined) — ex.: <Avatar size="sm" name={nome} />
- subtitle: string   (default: undefined)
- onClick: () => void   (default: undefined) — torna o rodapé um botão
- className: string   (default: undefined)
Helper sidebarNavIcon(Icon: LucideIcon): React.ReactNode — renderiza ícone Lucide em --icon-size/--icon-stroke.

## Proibido (do/don't)
DON'T: props collapsed, collapsible, width, onToggle — NÃO existem; a Sidebar é fixa em 240px.
DON'T: subcomponentes SidebarProvider/SidebarTrigger/SidebarMenu do shadcn stock — não existem neste DS.
DON'T: hex, rgb, px, rem em style inline; ícones fora de sidebarNavIcon perdem os tokens de traço.
DO: marque o item ativo com active: true (vira aria-current="page"); use badge para contadores.
