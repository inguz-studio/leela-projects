## Import canônico

Superfície pública (landing, ADR-017): import { FormGrid } from '@leela/design-system/server'

## Quando usar
Grade de campos de formulário: uma coluna no aparelho estreito, duas ou três a partir de um degrau. Serve qualquer bloco de itens de largura parecida (campos, cartões pequenos, células de resumo).

## Quando NÃO usar
Indicadores/KPIs são MetricGrid (a escada é outra, e a razão está no preset). Dois painéis de larguras diferentes são SplitPanel. Uma coluna só é Stack.

## Props válidas
- columns: 2 | 3   (default: 2)
- from: 'sm' | 'md' | 'lg'   (default: 'sm')   — o degrau em que a grade abre
- gap: 'sm' | 'md' | 'lg'   (default: 'md')
- as: 'div' | 'section' | 'fieldset' | 'form' | 'ul'   (default: 'div')
- ...todas as props de React.HTMLAttributes<HTMLDivElement>

## Tokens consumidos (nenhum valor cru permitido)
- --layout-list-gap (gap="sm") / --layout-grid-gap (gap="md", o default) / --layout-main-gap (gap="lg")

## Proibido (do/don't)
DON'T: columns={4} — quatro colunas é grade de indicador, e o componente dela é MetricGrid.
DON'T: className="grid-cols-2" para forçar duas colunas no estreito. A coluna única embaixo é contrato do sistema mobile-first, não default configurável.
DON'T: className="sm:grid-cols-2" num <div> em vez de usar o componente. Foram oito receitas assim que esta peça aposentou.
DO: campo que ocupa a linha inteira leva className="col-span-full" NO FILHO — vale para qualquer contagem de coluna e qualquer degrau.

## Instrução para o modelo (colar no system prompt)
Use o componente FormGrid apenas com as props e valores listados acima. Nunca escreva `grid grid-cols-*` à mão numa tela: as três famílias de grade têm componente publicado (FormGrid, MetricGrid, SplitPanel), e o que não couber nas três é decisão de cânone, não classe de tela.
