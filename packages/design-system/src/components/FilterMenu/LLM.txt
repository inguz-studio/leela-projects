## Import canônico
import { FilterMenu, type FilterMenuProps, type FilterMenuOption } from '@leela/design-system'

## Quando usar
Filtrar uma listagem/tabela por uma FACETA em MULTI-seleção (marcar Ativos + Encerrados de uma vez), com QUALQUER número de valores. O limiar Polaris de 4 valores governou esta peça até 16/08 e foi SUPERADO em 17/08 por decisão do dono: filtro de listagem é lista, sempre. Compõe DropdownMenu + itens menuitemcheckbox; vazio = sem filtro ("Todos"); o gatilho resume a seleção ("Status: 2").
Na prática você raramente monta este componente direto: quem escolhe entre ele e o Combobox é a FilterChips, pelo `multiple`.

## Quando NÃO usar
- Seleção ÚNICA exclusiva (radio-like): use Combobox. Um menu de menuitemcheckbox anunciaria "marcado" onde a semântica é "selecionado".
- Menu de AÇÕES (editar/excluir): use DropdownMenu direto (itens menuitem, fecham ao clicar).
- Fileira de Chip como filtro primário: proibida desde 17/08 (leva 20).

## Props válidas
- label: string   (obrigatório) — rótulo da faceta; aparece no gatilho e nomeia o menu.
- options: FilterMenuOption[]   (obrigatório) — FilterMenuOption = { id: string; label: string; count?: number }
- selected: string[]   (obrigatório) — ids marcados; [] = sem filtro.
- onChange: (next: string[]) => void   (obrigatório)
- allLabel: string   (default: 'Todos')
- align: 'left' | 'right'   (default: 'left')
- disabled: boolean   (default: false) — desliga o gatilho; sem gatilho não há menu (ADR-020).
- className: string   (default: undefined) — classe do PAINEL do menu, não do gatilho.
Nenhuma outra prop existe.

## Comportamento
- Multi-seleção: marcar uma opção não desmarca as outras (checkbox, não radio).
- Clicar num item NÃO fecha o menu (marca vários); Esc/click-fora/Tab fecham.
- Teclado herdado do DropdownMenu: setas, Home, End, Esc; foco no 1º item ao abrir.

## Proibido (do/don't)
DON'T: usar para seleção única exclusiva (isso é Select/Radio/Chip).
DON'T: aninhar o componente Checkbox real dentro do item (o indicador é visual/aria-hidden; a semântica é aria-checked no menuitemcheckbox).
DON'T: hex, rgb, px, rem em style inline.
DO: mantenha selected como fonte única (controlado); [] = "Todos".

## Exemplo mínimo (válido, copiável)
<FilterMenu label="Status" options={[{ id: 'ativos', label: 'Ativos' }, { id: 'encerrados', label: 'Encerrados' }, { id: 'rascunhos', label: 'Rascunhos' }]} selected={selected} onChange={setSelected} />

## Instrução para o modelo (colar no system prompt)
Use FilterMenu apenas para filtro de faceta MULTI-seleção com 4+ valores. Para seleção única, use Select. Só as props acima existem. Nunca aplique cor/espaço via literal; use tokens do design system.
