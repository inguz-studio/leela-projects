# FilterMenu

Filtro de faceta multi-seleção (checkbox em lista) num dropdown. É o par do Chip para o outro lado do limiar Polaris: faceta com menos de 4 valores segue como fileira de Chips; com 4+ valores vira este dropdown de checkboxes. Compõe o DropdownMenu (motor WAI-APG) com itens menuitemcheckbox e reusa a linguagem visual do Checkbox.
